Модуль оформляет обращения к Telegram по одной цели или по последовательности целей из базы,
с указанием категории и сохранением результата.

Описание раздела — на странице [Журнал жалоб Telegram](https://teletraff.com/ru/modules/reporter).

<Aside type="caution" title="Прочитайте это до настройки">
Модуль предназначен для обращений **по реальным нарушениям**: мошенничество, кража контента,
выдача себя за ваш бренд. Массовые жалобы на добросовестные ресурсы — злоупотребление, которое
вредит в первую очередь вашим же аккаунтам и не даёт заявленного результата.

Жалоба — это обращение к платформе, а не инструмент влияния на конкурентов.
</Aside>

## Что понадобится до запуска

- **Аккаунты с прокси.**
- **Конкретная цель** или база целей.
- **Основание.** Категория обращения должна соответствовать тому, что происходит на самом деле.

4. **Запустите и сохраните результаты для разбора.**

</Steps>

## Что модуль не делает

- **Не удаляет каналы и аккаунты.** Решение принимает Telegram, и панель на него не влияет.
- **Не гарантирует результат.** Отправленное обращение — это обращение, а не итог.
- **Не обходит ограничения платформы.**

Результат в журнале означает «обращение оформлено», а не «цель заблокирована».

## Частые ошибки

| Ошибка | Что происходит |
| --- | --- |
| Категория не по сути обращения | обращение не рассматривается по существу |
| Массовые жалобы на добросовестные ресурсы | страдают ваши аккаунты, цель остаётся на месте |
| Ожидание блокировки как результата запуска | журнал фиксирует отправку, а не решение платформы |

## Ограничения, согласие пользователей и правила платформы

Это единственный модуль панели, где злоупотребление наносит прямой вред третьим лицам.

- Оформляйте обращения только при реальных основаниях.
- Ложные жалобы нарушают правила Telegram и могут обернуться ограничениями для ваших аккаунтов.
- В ряде юрисдикций заведомо ложное обращение, направленное на причинение вреда чужому бизнесу,
  влечёт правовые последствия.
- Ответственность за содержание обращения несёт оператор.

Подробнее — [«Ответственное использование»](/responsible-use/).

## Частые вопросы

**Приведёт ли жалоба к блокировке?**
Решение принимает Telegram. Панель фиксирует факт обращения, а не его исход.

**Можно ли пожаловаться на несколько целей сразу?**
Да, поддерживается работа по базе целей.

**Сколько аккаунтов задействовать?**
Столько, сколько соответствует реальному числу людей, у которых есть основание для обращения.
Массовость сама по себе результата не добавляет.
