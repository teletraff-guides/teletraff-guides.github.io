## What TeleTraff is

TeleTraff is a panel for working with Telegram accounts and running common growth tasks: comments
under posts, account warmup, invitations to a channel, messaging, audience collection and result
tracking.

This knowledge base answers **how to do it**: the order of actions, what each field is for, a safe
test run and how to read what came back. Module overviews live on the
[official site](https://teletraff.com/en/modules).
